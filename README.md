# NabhoDhwani — Earth Jukebox (Accessibility First)

**NASA Space Apps Challenge 2026**
**Challenge: The Earth Information Jukebox**

> **“If you cannot see the data… you should still be able to hear it.”**

---

## The Problem

NASA’s Earth science data is powerful—but almost entirely **visual**:

* Satellite images
* Climate graphs
* Data visualizations

This creates a major barrier:

*  **Visually impaired users cannot access this information**
*  Complex graphs are not readable via screen readers
*  Scientific insights remain inaccessible to millions

 Earth data exists—but not for everyone.

---

##  Our Solution

**NabhoDhwani (Earth Jukebox)** transforms Earth data into **sound**.

Instead of seeing climate change, users can **hear it**.

We convert:

*  Temperature → Pitch
*  Rainfall → Sound intensity / noise
*  Data trends → Rhythm & variation

 This creates a **multi-sensory experience** where:

* Blind users can understand data
* Everyone can *feel* environmental change

---

##  Key Features

*  Real-time **data-to-sound conversion (sonification)**
*  Designed for **visually impaired accessibility**
*  Interactive **graph + sound synchronization**
*  Multi-layer audio (temperature + rainfall)
*  Live data integration via **NASA / weather APIs**
*  Simple and intuitive user interface

---

##  How It Works

1. **Data Input**

   * NASA datasets / APIs (temperature, rainfall, etc.)

2. **Mapping Engine**

   * Converts data into sound parameters
   * Example:

     * Temperature → frequency (pitch)
     * Rainfall → noise volume

3. **Sonification Engine**

   * Generates real-time audio using Web Audio / Tone.js

4. **User Interaction**

   * Slider / controls → explore data
   * Audio + optional visuals
